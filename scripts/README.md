# Scripts — Evolution VTT

Este diretório concentra scripts utilitários para automação local, apoio ao desenvolvimento, verificações auxiliares e manutenção do repositório.

## Estado atual

Diretório reservado na **Fase 0 — Fundação do Repositório**. Nenhum script operacional foi adicionado nesta tarefa.

## Convenções

- Cada script deve ter propósito claro, cabeçalho explicativo e comportamento previsível/idempotente sempre que possível.
- Prefira scripts portáveis ou documente explicitamente o ambiente/shell exigido (Bash, PowerShell, etc.).
- **Nunca** insira credenciais, tokens, senhas ou chaves de API diretamente em scripts; utilize variáveis de ambiente.
- Consulte as regras de governança e segurança em [`docs/development/governance.md`](../docs/development/governance.md).
