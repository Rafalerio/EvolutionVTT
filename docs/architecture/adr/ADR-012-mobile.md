# ADR-012 — Cliente Mobile

- **Status:** Aprovada

## Decisão
Começar com PWA responsiva e adaptada para dispositivos móveis.

## Evolução
Capacitor ou React Native podem ser avaliados posteriormente. A adoção de cliente nativo depende de limitações reais identificadas na PWA, não de antecipação.

## Consequências
A experiência mobile deve ser planejada desde o início, especialmente para a VTT, sem obrigar a criação imediata de uma aplicação nativa separada.
