# Guias de Desenvolvimento — Evolution VTT

Este diretório armazenará os guias práticos voltados ao dia a dia de desenvolvimento, configuração de ambiente e boas práticas operacionais dos módulos do **Evolution VTT**.

## Estado atual

Diretório preparado na **Fase 0 — Fundação do Repositório**. Os guias detalhados de execução e build serão adicionados conforme os projetos de backend, frontend e Docker Compose de desenvolvimento forem inicializados nas próximas tarefas da Fase 0.

## Guias planejados

- Configuração do ambiente local de desenvolvimento (Java, Node.js, Docker e variáveis `.env.example`).
- Guia de desenvolvimento do backend (estrutura de módulos, testes arquiteturais, Flyway e convenções Spring Boot).
- Guia de desenvolvimento do frontend (React + Vite + TypeScript, geração de tipos OpenAPI, Design System e camada de abstração do PixiJS).
- Guia de testes locais e validação de contratos (REST e WebSocket/STOMP).
